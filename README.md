# Zugverwaltung
Schulprojekt | HTL — Fach INFI

Ein Spring Boot Backend-System zur Verwaltung von Zügen, Waggons, Linien, Bahnhöfen und Fahrkarten, umgesetzt mit ORMLite und MySQL.
